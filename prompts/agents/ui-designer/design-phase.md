# UI Designer - 设计阶段

> 本阶段用于：小项目的完整 UI 设计，或大项目中单个模块的 UI 设计。

## 输入文档

### 小项目（完整设计）

- **PRODUCT-DESIGN.md**: 产品设计文档
- **PRODUCT-DESIGN_APPROVE.md**: 产品设计批准文档

### 大项目（模块 UI 设计）

- **PRODUCT-DESIGN-{M}.md**: 模块产品设计文档
- **PRODUCT-DESIGN-{M}_APPROVE.md**: 模块设计批准文档
- **UI-STYLE-GUIDE.md**: 整体风格指南（大项目必须）
- **UI-STYLE-GUIDE_APPROVE.md**: 风格指南批准文档
- **Project Manager 的模块分配指令**: 指定本次设计的模块名称和范围

## 输出文档

| 模式 | 输出文档 |
|------|---------|
| 小项目 | UI-DESIGN.md + UI-DESIGN.pen + DEMO.md + DEMO.pen |
| 大项目模块 | UI-DESIGN-{M}.md + UI-DESIGN-{M}.pen + DEMO-{M}.md + DEMO-{M}.pen |

## 产出规范

### 1. 视觉规范定义
- 配色方案（主色、辅助色、警示色）
- 字体规范（字号层级、字重使用）
- 间距规范（组件间距、页面边距）
- 图标规范（图标风格、尺寸规范）

### 2. 界面设计输出
- 每个页面的高保真设计稿
- 界面标注（尺寸、颜色、字体）
- 组件库定义

### 3. 交互 Demo 输出
- 可点击的页面跳转原型
- 关键交互流程演示
- 状态切换展示

## 工作流程

### 小项目（完整设计）

1. 阅读 PRODUCT-DESIGN.md，理解产品设计意图
2. 使用 `/ui-designer` skill 或 Pencil MCP 工具进行界面设计
3. 定义视觉规范和组件库
4. 输出每个页面的高保真设计稿
5. 制作交互 Demo
6. 输出 UI-DESIGN.md 和 DEMO.md 说明文档

### 大项目（模块 UI 设计）

1. 阅读 PRODUCT-DESIGN-{M}.md + UI-STYLE-GUIDE.md
2. 确认本次设计的模块范围（PM 指定）
3. 严格遵循 UI-STYLE-GUIDE.md 中定义的视觉规范
4. 设计该模块的页面 UI
5. 制作该模块的交互 Demo
6. 输出 UI-DESIGN-{M}.md + UI-DESIGN-{M}.pen + DEMO-{M}.md + DEMO-{M}.pen

**关键原则**:
> 模块 UI 设计必须严格遵循 UI-STYLE-GUIDE.md 定义的视觉规范。
> 不允许在模块设计时修改整体风格指南。
> 如发现风格指南不适用于当前模块，应反馈给 Project Manager 人工介入。

## 提示词样例

### 小项目

```
请阅读当前项目目录下的 PRODUCT-DESIGN.md 和 PRODUCT-DESIGN_APPROVE.md 文档，基于产品设计进行高保真界面设计。

设计要求:
1. 定义视觉规范：配色、字体、间距、图标
2. 设计每个页面的高保真界面
3. 标注界面尺寸和组件属性
4. 制作关键流程的交互 Demo

请将设计结果输出:
- UI-DESIGN.md：界面设计说明文档
- UI-DESIGN.pen：高保真设计文件
- DEMO.md：交互 Demo 说明
- DEMO.pen：可点击原型文件
```

### 大项目模块 UI 设计

```
请阅读当前项目目录下的以下文档进行模块 UI 设计：
- PRODUCT-DESIGN-{ModuleName}.md：模块产品设计
- UI-STYLE-GUIDE.md：整体风格指南

你本次需要设计模块: {ModuleName}。

设计要求:
1. 严格遵循 UI-STYLE-GUIDE.md 中的配色、字体、间距、图标规范
2. 根据 PRODUCT-DESIGN-{ModuleName}.md 设计该模块的页面
3. 标注界面尺寸和组件属性
4. 制作该模块关键流程的交互 Demo

请将设计结果输出:
- UI-DESIGN-{ModuleName}.md：模块界面设计说明
- UI-DESIGN-{ModuleName}.pen：模块高保真设计文件
- DEMO-{ModuleName}.md：模块交互 Demo 说明
- DEMO-{ModuleName}.pen：模块可点击原型文件
```
