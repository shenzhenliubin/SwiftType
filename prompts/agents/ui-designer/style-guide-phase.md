# UI Designer - 风格指南设计阶段

> 本阶段仅在大项目时触发。UID 在完成所有模块的产品设计评审后，先设计整体视觉风格指南，再交给 PM 编排各模块 UI 设计。

## 输入文档

- **PRODUCT-DESIGN-HIGH-LEVEL.md**: 高层产品设计（已通过 PR review）
- **PRODUCT-DESIGN-HIGH-LEVEL_APPROVE.md**: 高层设计批准文档
- **PRODUCT-DESIGN-{M}.md**: 各模块产品设计文档（已通过 PR review）
- **PRODUCT-DESIGN-{M}_APPROVE.md**: 各模块设计批准文档
- **Project Manager 的风格指南设计指令**: 指定设计整体风格指南

## 输出文档

- **UI-STYLE-GUIDE.md**: 整体风格指南说明文档
- **UI-STYLE-GUIDE.pen**: 整体风格指南设计文件

## 工作流程

### Step 1: 通读所有模块的产品设计

阅读 PRODUCT-DESIGN-HIGH-LEVEL.md 和所有 PRODUCT-DESIGN-{M}.md，理解：
- 产品整体定位和风格调性
- 各模块的页面类型和组件需求
- 跨模块共享的 UI 元素

### Step 2: 定义整体视觉规范

基于所有模块的需求，定义统一的视觉规范：

1. **配色方案**: 主色、辅助色、警示色、背景色、文字色
2. **字体规范**: 字号层级（H1-H6、正文、辅助文字）、字重使用、行高
3. **间距规范**: 页面边距、组件间距、内边距、栅格系统
4. **图标规范**: 图标风格（线性/填充/双色）、尺寸规范、使用场景
5. **组件库规范**: 按钮样式（主/次/禁用/加载）、输入框样式、卡片样式、导航样式、弹窗样式

### Step 3: 输出风格指南

输出 UI-STYLE-GUIDE.md 和 UI-STYLE-GUIDE.pen。

### Step 4: 等待 UIR review

风格指南提交给 UIR 评审，通过后 PM 开始编排各模块 UI 设计。

### 完整流程

```
UID 收到 PRODUCT-DESIGN-HIGH-LEVEL_APPROVE.md + PM 指令
    ↓
通读所有模块的产品设计（HIGH-LEVEL + 各模块 PRODUCT-DESIGN-{M}.md）
    ↓
定义整体视觉规范（配色、字体、间距、图标、组件库）
    ↓
输出 UI-STYLE-GUIDE.md + UI-STYLE-GUIDE.pen
    ↓
UIR review 风格指南 → 通过
    ↓
PM 按模块编排，派遣 UID 做各模块 UI 设计（进入 design-phase）
```

**关键原则**:
> 风格指南必须覆盖所有模块的 UI 需求。
> 风格指南设计时不涉及具体页面布局，只定义视觉规范和通用组件。
> 各模块的 UI 设计将严格遵循此风格指南。

## 提示词样例

```
请阅读当前项目目录下的以下文档进行整体风格指南设计：
- PRODUCT-DESIGN-HIGH-LEVEL.md：高层产品设计
- 所有 PRODUCT-DESIGN-{ModuleName}.md：各模块产品设计

你需要设计整个项目的视觉风格指南。

设计要求:
1. 配色方案：根据产品定位和各模块需求，定义主色、辅助色、警示色等
2. 字体规范：定义字号层级、字重使用、行高
3. 间距规范：定义页面边距、组件间距、栅格系统
4. 图标规范：定义图标风格和尺寸
5. 组件库规范：定义按钮、输入框、卡片、导航、弹窗等通用组件样式

风格指南需要覆盖所有模块的 UI 需求，确保整体风格统一。

请将设计结果输出:
- UI-STYLE-GUIDE.md：风格指南说明文档
- UI-STYLE-GUIDE.pen：风格指南设计文件
```
