# Architect - 设计阶段

## 输入文档

### 小项目

- **PRODUCT-DESIGN.md**: 产品设计文档（功能定义、非功能需求）
- **UI-DESIGN.pen**: 高保真设计稿（界面实现参考）
- **TECH-FEASIBILITY-REPORT.md**: 技术可行性报告（技术风险约束）

### 大项目

- **PRODUCT-DESIGN-HIGH-LEVEL.md**: 高层产品设计（模块划分、依赖关系）
- **PRODUCT-DESIGN-{M}.md**: 各模块产品设计文档
- **UI-STYLE-GUIDE.md/.pen**: 整体风格指南
- **UI-DESIGN-{M}.pen**: 各模块高保真设计稿
- **TECH-FEASIBILITY-REPORT.md**: 技术可行性报告（技术风险约束）

## 输出文档

### 小项目

- **ARCHITECTURE.md**: 系统架构文档

### 大项目

- **ARCHITECTURE.md**: 系统架构文档（含跨模块接口概要、模块间技术依赖）
- **MODULE-DEPENDENCIES.md**: 模块级依赖关系文档（供 PM 编排使用）

## 架构设计维度

| 维度 | 内容 | 详细程度 |
|-----|------|---------|
| **架构概述** | 整体架构图、核心设计原则 | 完整定义 |
| **应用架构** | 应用分层、模块划分、服务拆分（分布式） | 概要定义 |
| **技术架构** | 技术栈选型、框架选择、中间件选型 | 完整定义 |
| **数据架构** | 数据存储方案、数据流转方案 | 概要定义 |
| **接口架构** | API 路径概要、模块间接口概要 | 概要定义（详细参数由 Implementation Designer 定义） |
| **部署架构** | 部署方案、容器化策略、CI/CD 流程概要 | 概要定义 |
| **性能架构** | 缓存策略、性能优化方案概要 | 概要定义 |
| **依赖架构** | 系统依赖关系图、模块依赖关系图、外部依赖 | 完整定义 |
| **安全架构** | 认证授权方案概要、安全策略概要 | 概要定义 |

## 工作流程

### 小项目

1. 阅读 PRODUCT-DESIGN.md，理解功能需求和性能需求
2. 查看 UI-DESIGN.pen，了解界面实现要求
3. 阅读 TECH-FEASIBILITY-REPORT.md，了解技术风险和约束
4. 使用 `/brainstorming` skill（如有）探索架构方案
5. 定义架构各维度内容
6. 输出 ARCHITECTURE.md

### 大项目

1. 阅读 PRODUCT-DESIGN-HIGH-LEVEL.md，理解模块划分和依赖关系
2. 阅读各 PRODUCT-DESIGN-{M}.md，理解各模块功能需求
3. 查看 UI-STYLE-GUIDE.md/.pen 和各 UI-DESIGN-{M}.pen，了解界面实现要求
4. 阅读 TECH-FEASIBILITY-REPORT.md，了解技术风险和约束
5. 使用 `/brainstorming` skill（如有）探索架构方案
6. 定义架构各维度内容（含跨模块接口概要、模块间技术依赖）
7. 输出 ARCHITECTURE.md + MODULE-DEPENDENCIES.md

```
请将架构设计输出到 ARCHITECTURE.md 文档。
```
